# PixelDiet 1.1.0 - App Review Information

Paste the "Notes" section into App Store Connect → App Review Information → Notes (limit 4000 bytes).

## Sign-in information

Sign-in required: **No**. PixelDiet has no accounts, no sign-in, no in-app purchases and no network features, so no demo account or backend access is needed.

## Contact information

**OWNER:** first name, last name, email, and a phone number in international format with a leading `+` (App Store Connect rejects digits-only numbers). These are not shown publicly.

## Notes

```
PixelDiet is an offline batch image compressor. No account, network connection or purchase is needed.

How to review:
1. Launch PixelDiet and click "Browse Files" (or choose File > Add Images..., or drag images or a folder onto the window). Any JPEG, PNG or HEIC photos work, for example from the Pictures folder.
2. In the left sidebar, click "Choose Output Folder..." (or File > Choose Output Folder...) and select or create an empty folder, e.g. "PixelDiet Output" on the Desktop. It must not be the folder that holds the source images, or a folder that contains it (a new folder inside it is fine).
3. Pick an output format (e.g. WebP), optionally adjust Quality and "Max Longest Edge", then click the Compress toolbar button (Command-R).
4. Double-click any image, or select it and press Space, to open the Before/After Preview. Click "Open Output Folder" to see the compressed copies. The original files are never modified.

Notes:
- Window: closing the main window keeps the queue; Window > PixelDiet or the Dock icon brings it back. Quitting during a batch asks for confirmation first.
- Help: Help > PixelDiet Help explains every feature; the Help menu also links to support, bug reports, the source code and the privacy policy.
- App Sandbox: PixelDiet only reads files and folders the user selects in the open panel or drags onto the window, and writes only to the output folder the user chooses. The output folder is remembered with a security-scoped bookmark. No temporary-exception entitlements are used.
- Notifications: a permission request appears only if a batch finishes while PixelDiet is in the background; it is used only for a local "batch complete" notification.
- Privacy: no data is collected or transmitted; all processing happens on the Mac.
- Open source: WebP encoding uses the bundled libwebp library (BSD license), shown in About PixelDiet > Acknowledgements.
```
